# UFOP-Introducao-a-Programacao
Repositório criado para registrar minha evolução na programação durante o Bacharelado em Inteligência Artificial na UFOP.
## Programas

| # | Programa | O que faz | Exemplo |
|---|----------|-----------|---------|
| 01 | [Conversão de temperatura](01-conversao-temperatura.c) | Celsius para Fahrenheit e Kelvin | 32 → 89.60 e 305.15 |
| 02 | [Expressão com pow](02-expressao-com-pow.c) | Calcula x = a³ · (b + c) / d | 10 10 10 10 → 2000 |
| 03 | [Horas em segundos](03-horas-em-segundos.c) | Converte hora, minutos e segundos em segundos | 1 10 20 → 4220 |
| 04 | [Expressão de y](04-expressao-y-com-pow.c) | Calcula y = (x1 + x2² + x3²)² − (x1·x2·x3)² | 1 1 1 → 8.00 |
| 05 | [Simulador de dados RPG](05-simulador-de-dados-rpg.c) | Sorteia um número de 1 até o total de faces | 20 faces |
| 06 | [Comparaco de pontuações](06-comparacao-de-pontuacoes.c) | Para descobrir e informar qual time possui a maior pontuação e qual possui a menor |
| 07 | [Relatório de notas universitárias](07-relatorio-de-notas-universitarias.c) | Este sistema será usado para gerar o histórico acadêmico |
